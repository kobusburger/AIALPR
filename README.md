This app was created with Android Studio

It starts with a camera preview with a button to take a photo of cars and a history button

It requires a snapshot token. See https://guides.platerecognizer.com/docs/snapshot/api-reference/?shell#license-plate-recognition/

The numberplates (can be multiple on a photo) is saved in an SQLite database with links to the photos. The photos are stored in a folder

The history screen has a download button to save a zip file to a user selectable location containing the database in a csv file and the photos in a folder

The history screen also has an upload button to import a csv file with additional numberplate information with the plate as key
